# Coverage Summary (Phase 2)

**What this is.** *Functional* coverage counted by the testbench monitor (`testbench/tb_common.vh`) from the actual simulation: FSM states and transitions visited, cache indices/offsets exercised, hit/miss classes. **What it is not.** No RTL *line/branch/toggle* coverage tool was used or run (Icarus Verilog has none; Verilator coverage was not enabled), so **no line-coverage percentage is claimed.** All counts below are taken from the saved logs `build/d_L*.log` (regenerated by `scripts/phase2_regression.sh`).

## FSM transition coverage (the 17 legal transitions)

`IDLE->IDLE, IDLE->COMPARE_TAG, COMPARE_TAG->{READ_HIT, READ_MISS, WRITE_HIT, WRITE_MISS}, READ_HIT->RESPONSE, READ_MISS->MEMORY_READ_WAIT, WRITE_MISS->MEMORY_READ_WAIT, MEMORY_READ_WAIT->{MEMORY_READ_WAIT, REFILL}, REFILL->{READ_HIT, WRITE_HIT}, WRITE_HIT->MEMORY_WRITE_WAIT, MEMORY_WRITE_WAIT->{MEMORY_WRITE_WAIT, RESPONSE}, RESPONSE->IDLE`. All 17 were visited at every latency except L=1, where the read-wait state lasts one cycle so the `MEMORY_READ_WAIT->MEMORY_READ_WAIT` self-loop cannot occur (16 reachable transitions, all visited).

The six unused state encodings (10-15) are covered by test E-11 (forced into each code; outputs quiet; self-recovers to IDLE in one clock).

## Requirement-level coverage

Spec-section 2.1 tests 1-30 map to IDs D-01..D-30 (D-24 is split into D-24, D-24R, D-24W, D-24A for reset in each transaction type); 2.2 edge cases map to E-01..E-11; all are in `TEST_RESULTS.md`. The independent reference-model comparison (`results/reference_model_results.txt`) adds 714666 randomized/vector transactions in 8 workload profiles with fixed seeds.

## Not covered / limits

* No RTL line/branch/toggle coverage numbers (no tool run).
* `LATENCY` values > 65535 are outside the 16-bit counter range and untested (documented limit).
* Per-transaction random latency is tested only through the testbench-only `tb_mem_varlat` model, not through `rtl/main_memory.v`.
* Simultaneous multi-master or pipelined requests are not supported by the design and not tested.
